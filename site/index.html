// FEATURES

为具身 AI 工作负载而生

不是通用数据库的裁剪版——每个能力都对着机器人数据的真实形状设计。

多模态原生

VECTOR(n) 向量列带索引 KNN、BLOB 字节等值、全文检索与 TIME_BUCKET 时序聚合——同一个 SQL 引擎，同一个事务视图。

三种形态一种体验

采集期是高性能目录，运输期是单文件快照（CRC 校验 + zstd），部署期是只读容器直开——EXPORT DB 一条 SQL 串联。

嵌入式零运维

无服务、无端口、无独立进程。库文件即数据库，索引损坏自动从源数据重建，打开即用。

断电安全内核

temp+fsync+rename 原子发布、WAL 组提交、孤儿段领养、崩溃注入与差分模糊测试持续验证——边缘设备的拔电是常态而非异常。

五平台预构建

macOS (arm64/x64)、Linux (x64/arm64)、Windows 的官方二进制直接安装——交叉编译与冒烟测试在 CI 里逐平台验证。

舰队友好

快照增量重导出、只读容器多读者共存、字典序数据自愈——为"一台指挥、百台采集"的机器人舰队同步而设计。

5 分钟：从 MCAP 到可查询的时序库

  • 建表即声明多模态：TIMESERIES(ts) 时序语义、VECTOR(4) 向量列
  • 参数化写入，预编译语句缓存
  • 向量 KNN 用熟悉的 <-> 算符，索引加速
  • 重开自动恢复：WAL 回放 + 段迁移 + 索引自愈
# pip install motedb-python
from motedb import Database

db = Database("robot.mote")
db.execute("CREATE TABLE poses (
  ts TIMESTAMP, sid INT, emb VECTOR(4)
) TIMESERIES(ts)")
db.executemany("INSERT INTO poses VALUES (?,?,?)",
               poses)

# 向量 KNN：最近的 5 个位姿
hits = db.query("SELECT ts, sid FROM poses
  ORDER BY emb <-> [0.1,0.2,0.3,0.4] LIMIT 5")

# 运输：整库打成单文件快照
db.execute("EXPORT DB TO 'fleet.mote'")
